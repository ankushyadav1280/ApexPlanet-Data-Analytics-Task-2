# ApexPlanet Data Analytics Internship — Task 2

## Exploratory Data Analysis (EDA) & Business Intelligence

### Project Overview
This project focuses on analyzing sales transaction data using Python, SQL, and Excel to discover business insights, understand sales performance, and present key findings through visualizations and a dashboard.

### Objectives
- Perform Exploratory Data Analysis (EDA).
- Calculate descriptive statistics and analyze numerical and categorical variables.
- Answer business questions using SQL queries.
- Study relationships between numerical variables using correlation analysis.
- Create an Excel dashboard to summarize important sales KPIs.

### Tools & Technologies
- **Python:** Data analysis and visualization
- **Pandas:** Data manipulation and aggregation
- **Matplotlib / Seaborn:** Data visualization
- **SQLite:** SQL business queries
- **Jupyter Notebook:** Analysis workflow
- **Microsoft Excel:** Dashboard and KPI presentation
- **GitHub:** Project documentation and version control

### Dataset
The dataset contains 1,000 sales transaction records and 22 columns in the analyzed DataFrame, including fields such as order date, customer information, city, product, category, quantity, unit price, and total sales.

### Key Findings
- **Total Sales:** ₹13,93,99,439.65 (approximately ₹13.94 crore).
- **Top Revenue Category:** Electronics, with sales of ₹5,07,78,581.70.
- **Top City by Sales:** Patna, with sales of ₹1,92,85,966.89.
- **Quantity vs Total Sales:** Positive correlation of 0.65.
- **Unit Price vs Total Sales:** Positive correlation of 0.69.
- **Age vs Total Sales:** Correlation is approximately 0.00 in this dataset.

These findings describe the analyzed data and do not establish causation.

### Project Files
- `EDA.ipynb` — EDA notebook, analysis, and visualizations
- `EDA_Report.pdf` — Summary report of the analysis
- `Dashboard_Data.xlsx` — KPI and chart data for the dashboard
- `SQL_Query_Results.xlsx` — Results of SQL business queries
- `SQL_Queries.sql` — SQL queries used for business analysis

### Business Questions
1. Which five products generate the highest revenue?
2. Which product category generates the most sales?
3. Which five cities have the highest sales?
4. How do sales vary by month?
5. Which products sell the highest quantity?
6. How is revenue distributed by gender?
7. How does revenue vary across customer age groups?

### Conclusion
The analysis identifies the leading sales category and city and highlights positive relationships between quantity, unit price, and total sales. The results can help support further investigation into sales performance and business trends.
